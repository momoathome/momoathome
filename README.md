## Hi, I'm Maurice 👋

Full-stack web developer from Bavaria, Germany. Five years of building web applications with TypeScript, Vue 3, Node.js (Fastify), GraphQL and PostgreSQL.

I build software with coding agents (Claude Code, Codex): I write the specs, set the architecture and review every change. I care about clean module boundaries (modular monolith, DDD) and about AI workflows the whole team can use, from `AGENTS.md` conventions to multi-agent pipelines.

An adapted version is used daily by my team at xitavis.
